# Help Screenshots

Place screenshot images here. They are referenced by the help content in
`src/lib/config/helpContent.ts`.

If an image file is missing, the help modal falls back to a text placeholder
automatically — no errors are shown to the user.

## Tips for taking screenshots

- Capture at ~1280px wide for consistency
- Crop tightly around the relevant UI area
- Use PNG format
- Annotate with arrows or highlights if helpful
